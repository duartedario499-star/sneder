SMTP Sender PHP
================

Requisitos:
- PHP 8+
- Extensión OpenSSL habilitada para TLS/SSL.

Instalación:
1. Subí index.php, config.json y .htaccess a una carpeta de tu hosting.
2. Abrí index.php desde el navegador.
3. Completá los datos del SMTP.
4. Guardá la configuración.
5. En "Nuevo correo" indicá destinatario, asunto y HTML.
6. Presioná "Enviar correo".

Importante:
- No publiques ni compartas config.json.
- Usá únicamente un SMTP que administres o para el que tengas autorización.
- El proyecto está pensado para envíos individuales/transaccionales, no para spam o listas no consentidas.
